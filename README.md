## Run Locally

### Prerequisites

* Node.js

### Installation

1. Install dependencies:

```bash
npm install
```

2. Set the `GEMINI_API_KEY` in `.env.local`:

```env
GEMINI_API_KEY=your_api_key_here
```

3. Run the application:

```bash
npm run dev
```

4. Open your browser and visit:

```text
http://localhost:3000
```
